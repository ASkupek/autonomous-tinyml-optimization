autonomous-tinyml-optimization.config

Global Configuration Parameters for the CARLA-Kafka ML Pipeline.

This module acts as a single source of truth for all network settings, Kafka configurations, data paths, and hyperparameters used across the streaming, consuming, and ML training pipelines.

Note:
